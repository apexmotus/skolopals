| `src/lib/database.types.ts` | `src/database.types.ts` | `apps/client`, `apps/admin`, `packages/ui` | Generated by `cd db && make types`. Exports `Database`, `Tables`, `Row<T>`, `AppRole`, etc. |
| `src/lib/api/client.ts` | `src/api/client.ts` | `apps/client`, `apps/admin` | `server-only` fetch wrapper (`api.get`, `api.getPaged`, `api.post`, `api.patch`, `api.put`, `api.delete`, `ApiError`, `Paged<T>`). |

| `src/lib/supabase/client.ts` | `src/supabase/client.ts` | `apps/client`, `apps/admin` | Browser `@supabase/ssr` client factory. |
| `src/lib/auth.ts` | `src/auth.ts` | `apps/client`, `apps/admin` | Exports `Session`, `getSession()`, `requireUser()`, `requireRole()`, `clientHomeFor()` (client roles only), and `requireAdmin()` (admin app gate). See `03-app-architecture-and-auth-boundaries.md`. |
| `src/lib/format.ts` | `src/format.ts` | `apps/client`, `apps/admin`, `packages/ui` | Pure formatting helpers (`money`, `formatRandSpaced`, `shortDate`, `dateTime`, `clockTime`, `dayName`, `relativeDay`, `age`, `initials`, `firstName`, `greeting`, `nowMs`, `INVOICE_STATE_LABEL`, `DELIVERY_MODE_LABEL`). |
| `src/lib/format.test.mts` | `src/format.test.mts` | `packages/shared` | Unit tests for formatting functions. |
| `src/lib/queries.ts` *(reference subset)* | `src/reference.ts` | `apps/client`, `apps/admin` | Reference data lookups shared by both apps: `getPhases()`, `getGrades()`, `getSubjects()`, `getLanguages()`, `getRooms()`, and types `Phase`, `Grade`, `Subject`, `Language`, `SubjectOffering`, `Room`. |

> **Why `src/lib/queries.ts` is split:** Grep across `web/src/app/admin/` confirms that `admin/tutors/[id]/page.tsx` and `admin/timetable/page.tsx` only import `getGrades`, `getLanguages`, and `getSubjects` from `lib/queries.ts`. All other functions in `lib/queries.ts` (`getSubjectsByPhase`, `getPackages`, `searchTutors`, `getTutorBySlug`, `getPublishedReviews`, `getPublicTimetable`, `getOperatingHours`, `getPublishedProgrammes`) are used exclusively by `(public)` routes in `apps/client` and stay in `apps/client/src/lib/queries.ts` (which re-exports `@skolopals/shared/reference` for convenience).
